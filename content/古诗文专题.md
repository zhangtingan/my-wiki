## 虚词用法

### 之

1. **代词** - 指代人、事、物
   > 君将哀而生之乎（代自己）

2. **助词** - 的
   > 邻之厚，君之薄也

3. **助词** - 取独（取消句子独立性）
   > 孤之有孔明，犹鱼之有水也

4. **动词** - 到、往
   > 送孟浩然之广陵

### 于

1. **介词** - 在
   > 海运将徙于南冥

2. **介词** - 从
   > 庄子送葬，过惠子之墓

3. **介词** - 比
   > 苛政猛于虎也

4. **介词** - 给
   > 故天将降大任于是人也

### 以

1. **介词** - 用、把、拿
   > 具以情告

2. **介词** - 因为
   > 不以物喜，不以己悲

3. **连词** - 表目的
   > 劳其筋骨，饿其体肤

4. **连词** - 表修饰
   > 船载以入

## 文言句式

### 判断句

| 格式 | 例句 |
|------|------|
| ……者，……也 | 陈胜者，阳城人也 |
| ……者也 | 城北徐公，齐国之美丽者也 |
| 无标志 | 刘备，天下枭雄 |
| ……乃…… | 当立者乃公子扶苏 |

### 被动句

| 格式 | 例句 |
|------|------|
| 于字句 | 身死人手，为天下笑 |
| 为字句 | 身死人手，为天下笑者 |
| 见字句 | 秦城恐不可得，徒见欺 |
| 被字句 | 仍更被驱遣 |

### 倒装句

**宾语前置：**
- 否定句中代词宾语前置
  > 古之人不余欺也
- 疑问句中疑问代词宾语前置
  > 大王来何操？
- 以字结构宾语前置
  > 夜以继日

**状语后置：**
> 青取之于蓝而青于蓝
> 告之于帝


### 答题模板

#### 鉴赏诗歌语言

```
1. 找特点（关键词）
2. 分析表达效果
3. 表达感情

示例：
"春风又绿江南岸"中"绿"字好在：
① 形容词用作动词，形象生动
② 视觉角度写出春满大地的景象
③ 蕴含作者对家乡的思念之情
```

#### 鉴赏诗歌形象

```
1. 是什么形象
2. 形象特征
3. 形象意义

示例：
"采菊东篱下，悠然见南山"
→ 塑造了隐士陶渊明的形象
→ 闲适、淡泊、与自然融为一体
→ 表达对官场的厌恶和对自然的热爱
```

## 名句默写

### 64篇必背篇目重点句

#### 《劝学》重点句
- [ ] 学不可以已
- [ ] 青，取之于蓝而青于蓝
- [ ] 君子博学而日参省乎己

- [ ] 师者，所以传道受业解惑也

- [ ] 句读之不知，惑之不解
- [ ] 是故弟子不必不如师

#### 《赤壁赋》重点句
- [ ]清风徐来，水波不兴
- [ ] 月出于东山之上，徘徊于斗牛之间
- [ ] 寄蜉蝣于天地，渺沧海之一粟
- [ ] 盖将自其变者而观之，则天地曾不能以一瞬
